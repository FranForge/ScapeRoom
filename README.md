## Español - Acerca del Repositorio

Este repositorio alberga un proyecto desarrollado en Unreal Engine 5 utilizando C++.  
Se trata de un proyecto ligero del género *Escape Room* en primera persona, que incluye mecánicas como movimiento del personaje, gestión de stamina, control de cámara en primera persona, interacciones y un sistema de inventario.  
El proyecto se encuentra en desarrollo, y se irán incorporando nuevas mecánicas y funcionalidades progresivamente para convertirlo en una demo jugable.

---

## Estado del Proyecto

El proyecto actualmente está en desarrollo y la meta es una demo técnica jugable con un solo nivel.  
Es un proyecto de prueba para Unreal Engine, aunque no se descarta continuarlo en el futuro.

---

## Requisitos

- Unreal Engine 5.7.2  
- Visual Studio configurado para C++

---

## Instalación

Actualmente, la instalación consiste únicamente en clonar el proyecto y abrirlo en Unreal Engine. En un futuro se añadirá un ejecutable de prueba.  

1. Clonar el repositorio:  
git clone https://github.com/FranForge/ScapeRoom.git

2. Abrir el proyecto con Unreal Engine 5.7.2.

3. Compilar la solución desde Visual Studio antes de ejecutar el proyecto para evitar errores.

## English - About this Repository

**Last edited README.md: 10/02/2026**

This repository contains a project developed in Unreal Engine 5 using C++.  
It is a lightweight first-person *Escape Room* project featuring mechanics such as character movement, stamina management, first-person camera control, interactions, and an inventory system.  
The project is under active development, and additional mechanics and features will be gradually added to create a playable demo.

---

## Project Status

The project is currently under development, aiming to be a playable technical demo with a single level.  
It is a test project for Unreal Engine, though it may be continued in the future.
